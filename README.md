# WEB-LR-1-Campus
Назва проекту: Campus
Опис: Проект спрямований на створення дошки оголошень, де студенти зможуть купляти або продавати вживані товари

Ролі: гість, користувач, модератор, адміністратор

Функціональні вимоги:
•	Система має дати гостю можливість створити аккаунт
•	Система має дати користувачу можливість увійти в аккаунт
•	Система має дати користувачу можливість вийти з аккаунта
•	Система має дати користувачу доступ до редагування лише для своїх оголошень
•	Система має дати користувачу доступ на створення оголошення
•	Система має дати користувачу доступ до зв’язку з продавцем
•	Система має дати користувачу доступ до створення власного оголошення
•	Система повинна дати користувачу можливість придбати й оплатити послугу просування.
•	Система повинна дати користувачу можливість прив’язати банківську картку, щоб постійно не вводити її дані.
•	Система повинна дати модератору можливість переглядати чергу з неперевірених оголошень / аккаунтів.
•	Система повинна дати модератору можливість видалити оголошення, якщо під час перевірки було знайдено порушення правил платформи
•	Система повинна дати модератору можливість заблоковувати аккаунти з підозрілою активністю.
•	Система повинна дати адміністратору можливість назначати / прибирати модераторів
•	Система повинна дати адміністратору доступ до зміни платформи, підписок, тарифів, акцій, каталогів, незмінних сторінок.
Нефункціональні вимоги:
•	Система має тимчасово блокувати вхід до аккаунта, якщо було більше 3 невірних спроб входу
•	Система має забороняти створювати більше 1 аккаунта на одну електронну пошту.
•	Система має підтримувати підключення більше 300 одночасних користувачів
•	Система має підвантажувати каталоги не більше ніж за 2 секунди після відкриття
•	Система має обмежувати розмір завантажуваних файлів (до 10 мб за фото)
•	Система має пропускати паролі мінімум з 8 символів
•	Система має мати обмеження до запитів з однієї адреси (або імітувати затримку для захисту від перенавантаження).
•	Система має підтримуватись на мобільних та десктопних пристроях.
•	Система має адаптуватись розширенням під конкретний пристрій (зміна розміру елементів відносно використання мобільного пристрою чи десктопного).
